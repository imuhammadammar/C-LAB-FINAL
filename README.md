# 🏦 C++ Banking System (Lab Final Project)

This project is a **console-based Banking System** developed in **C++** as part of a **C++ Programming Lab Final Examination**.  
The program simulates basic banking operations using a menu-driven approach.

---

## 📌 Project Description

The Banking System allows a user to securely access their account using a **PIN code**.  
After successful authentication, the user can perform basic banking operations such as checking balance, depositing money, and withdrawing money.

This project focuses on implementing **core C++ programming concepts** rather than real-world banking security.

---

## ✨ Features

- 🔐 PIN-based authentication  
- 💰 Balance inquiry  
- ➕ Deposit money  
- ➖ Withdraw money  
- 🔁 Multiple transactions in one run  
- 🚪 Exit option  

---

## 🛠️ Technologies Used

- **Language:** C++
- **Programming Concepts:**
  - Variables and data types
  - Conditional statements (`if`, `else`, `switch`)
  - Loops (`while`, `do-while`)
  - Functions
  - Input and output (`cin`, `cout`)
